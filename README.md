# Ручное тестирование

## Окружение
- Браузер: Chrome
- URL: `http://localhost:8000/?balance=30000&reserved=20001`

# Тестовые сценарии перевода средств

## TC-001. Открытие формы перевода из рублёвого счёта

### ID
TC-001

### Название (Title)
Открытие формы перевода из рублёвого счёта

### Описание (Summary)
Проверка перехода к форме перевода после выбора рублёвого счёта.

### Приоритет (Priority)
High

### Предусловия (Preconditions)
1. Сервис запущен локально из папки `dist` командой `python3 -m http.server 8000`.
2. Открыта страница `http://localhost:8000/?balance=30000&reserved=20001`.

### Шаги (Steps to reproduce)
1. Открыть главную страницу сервиса.
2. Найти блок счёта с заголовком «Рубли».
3. Нажать на блок «Рубли».

### Ожидаемый результат (Expected result)
1. Открывается форма перевода.
2. Пользователю отображается поле ввода номера карты.

## TC-003. Проверка валидации номера карты из 17 цифр

### ID
TC-003

### Название (Title)
Проверка валидации номера карты из 17 цифр

### Описание (Summary)
Проверка, что сервис не позволяет продолжить перевод при вводе номера карты длиной более 16 цифр.

### Приоритет (Priority)
High

### Предусловия (Preconditions)
1. Сервис запущен локально из папки `dist` командой `python3 -m http.server 8000`.
2. Открыта страница `http://localhost:8000/?balance=30000&reserved=20001`.
3. Открыта форма перевода из рублёвого счёта.

### Шаги (Steps to reproduce)
1. На главном экране нажать на блок рублёвого счёта с заголовком «Рубли».
2. В поле ввода номера карты ввести 17 цифр, например: 11112222333344445.
3. Обратить внимание, что появляется форма ввода «Сумма перевода».
4. Ввести валидную сумму перевода, например 1000.
5. Обратить внимание на подсвечивание кнопки «Перевести» и возможность перейти к переводу.

### Ожидаемый результат (Expected result)
1. Номер карты должен считаться невалидным, так как должен состоять ровно из 16 цифр.
2. При номере карты длиной 17 цифр форма «Сумма перевода» не появляется.
3. Кнопка «Перевести» не становится доступной, перевод инициировать нельзя.

## TC-005. Проверка валидации отрицательной суммы перевода

### ID
TC-005

### Название (Title)
Проверка валидации отрицательной суммы перевода

### Описание (Summary)
Проверка, что сервис не позволяет продолжить перевод при вводе отрицательной суммы.

### Приоритет (Priority)
High

### Предусловия (Preconditions)
1. Сервис запущен локально из папки `dist` командой `python3 -m http.server 8000`.
2. Открыта страница `http://localhost:8000/?balance=30000&reserved=20001`.
3. Открыта форма перевода из рублёвого счёта.
4. Введён валидный номер карты из 16 цифр, отображается поле «Сумма перевода».

### Шаги (Steps to reproduce)
1. На главном экране нажать на блок рублёвого счёта с заголовком «Рубли».
2. В поле ввода номера карты ввести валидный номер из 16 цифр, например: 1111222233334444.
3. Дождаться появления формы ввода «Сумма перевода».

3. Кнопка «Перевести» должна оставаться недоступной до ввода положительной валидной суммы.
